# High-end-desktop performance target

The sim targets mid-to-high-end desktop hardware at 60fps; low-end and mobile devices are explicitly out of scope. Chosen so the visual budget (bloom, soft shadows, dense starfield, atmosphere shaders) can be spent freely in service of the primary goal — visually appealing and fun to explore. This is a scope boundary, not a technical accident: the input model, asset quality, and rendering pipeline all assume a mouse/keyboard desktop experience.

**Considered Options**: mid-range laptops and mobile support — rejected: constrains the visuals against the primary goal, and the touch input model would dilute the free-exploration experience.
