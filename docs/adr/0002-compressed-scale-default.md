# Compressed scale by default, with a true-scale toggle

The sim renders bodies enlarged and distances compressed by default (compressed mode); a toggle switches to true-scale mode, which shows real distances while keeping bodies at a readable minimum size. Chosen because the real solar system is ~99.999% empty — at true scale nothing is visible and motion is imperceptible, which fails the entertainment-first goal. The toggle preserves the educational payoff: feeling the real emptiness of the gaps.

**Considered Options**: full honesty in true-scale mode (bodies at true size) — rejected: planets shrink to sub-pixel specks and the user loses their place; always-true-scale — rejected: unplayable as the default experience.
